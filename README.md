## 当前版本 · v0.2.0（2026-09-14）

### 本次更新

- 三个收款码共用“内部码颜色”；赞赏码中心预设图案和右下角图标会同步着色，用户上传的中心头像保持原色。
- 缩小赞赏码中心的白色遮罩区域，保留更多原始码点；支持夜间截图背景清理和中心头像对齐。
- 后台可分别调整并保留三个二维码的主体尺寸与位置，桌面预览和导出遵循已保存的布局。
- 优化手机端高清 PNG 生成与长按保存流程，并整理四步制作界面、颜色控件和预览体验。

### v0.1.0

- 上传的收款码不再保留原码模式，统一按模板样式生成；支付宝、微信和赞赏码的样式与颜色设置均采用互斥展开面板，一次只展开一项。
- 赞赏码的中心头像、右下图标和二维码颜色统一为与其他二维码一致的控制布局；A2C 已移除，历史 A2C 配置会自动兼容为 A2。
- 模板素材未关联当前模板时即可删除，不受历史版本引用限制；后台的“恢复默认”统一恢复为该模板后台已保存的默认参数。
- 手机端预览取消“查看大图”和顶部提示，成品始终以放大模板展示；移除收款码上传与颜色说明区，功能区上移，底部保留个人使用声明。
- 后台可选背景以 1、2、3、4 编号展示，便于定位和管理。

## 本地运行

要求 Node.js 24.18+、npm、Python 3.11+（仅 PSD 准备阶段需要）。

```powershell
npm ci
python -m pip install -r scripts/requirements.txt
python scripts/inspect-psd.py "你的模板.psd"
python scripts/prepare-template.py "你的模板.psd"
# 将授权字体复制到 public/private-assets/template.ttf
npm run admin:setup
npm run dev
```

打开 `http://localhost:8982`；管理员入口 `http://localhost:8982/admin`。随机管理员密码保存在 `.local/admin-access.txt`，散列保存在 `.env.local`。脚本不会覆盖已存在的管理员配置。收款截图和前台上传的图片不上传服务器、不保存到 localStorage；关闭或刷新页面会丢失当前编辑，浏览器会在支持时提示。

第一版的 PSD 提取脚本专门映射已确认的模板结构，**不支持任意 PSD 自动转换**。仓库不包含私人模板和字体；首次运行需要提供授权素材。缺少素材时前台显示暂无模板，不会用虚构模板代替。`data/seed.json` 仅在空数据库初始化时导入，之后模板编辑、发布和历史恢复在后台完成。重新提取素材不会改写历史版本数据库。

已有首版模板可运行 `npx tsx scripts/enable-label-language.ts` 启用二维码下方的中英文单选。该命令保留历史快照，为当前模板创建新版本，并更新草稿和种子；重复运行不会重复创建版本。

## 已实现

- “新增素材”支持多选图片和拖拽批量上传，按当前模板的素材分类自动编号并依次追加；显示上传进度，部分失败可单独重试，成功项不会丢失。

- 后台“图层与权限”将背景图层与可选背景素材集中在“可替换背景”文件夹；在文件夹中新增素材，保存并发布后供用户选择。前台“提供的背景 / 自己上传”单选切换，保留本次上传图片，预览与高清导出同步。

已有本地预览模板可运行 `python scripts/dividers.py "你的模板.psd"`，再运行 `npx tsx scripts/install-dividers.ts` 加入分割线选项。升级保留其他设置与旧版本，不覆盖已验收发布的模板。专项验证：`node scripts/qa-dividers.mjs`。

- PSD「分割线」73 款单选：左右循环切换、下拉直接选款、缩略预览和恢复默认；保留原坐标及颜色叠加，预览与导出仅绘制所选款式。两个同名「72」分别标识。

- 单页制作：进入即上传三个码，默认使用已发布模板；左侧实时预览，右侧上传、按需展开内容/样式并直接下载高清 PNG。
- 微信、支付宝完整截图本地识别；A1/A1C/A1P、A2/A2C 独立参数；确定性随机图形。
- 赞赏码自动定位和裁剪，按管理员设置的尺寸放置；用户端不提供码体取景、缩放。PSD 中心头像 5 款、右下图标 3 款独立切换；中心头像支持用户上传，右下图标仅选预设。
- 后台“三码放置区域”分别设置三个码的主体尺寸和位置，支持拖动、等比缩放、数值输入、框内居中和恢复已保存设置。三个外框锁定，赞赏码头像和图标覆盖层随码区域同步对齐；前台不提供码尺寸或位置设置。
- 两个二维码以矩阵边界作为主体尺寸，四模块安全留白额外计算，上传截图边距不影响大小。后台可本地上传真实截图测试，显示主体与留白边界；安全留白碰到固定外框时停止生成并提示，不自动缩小或裁掉留白。赞赏码将裁剪结果等比例映射到固定区域。新规则只升级后台草稿，保存并发布后供新作品使用，旧版本保留原渲染规则。
- 后台“更改默认展示”复用前台编辑器：修改三个默认码、主头像、码中头像、背景、文字及样式；保存时将上传图片登记为素材，发布后成为前台初始展示。默认码不计入用户上传数量；前后台均可点击“下一步”展开内容与样式，未上传或仅上传部分码也可直接下载，缺少的码沿用默认展示。
- “图层与权限 → 新增素材”直接添加背景、头像、赞赏头像和右下图标到当前模板，发布后供用户选择；背景和头像仍支持用户上传。仅赞赏码支持中心头像替换，按 PSD 正方形区域裁切和显示；微信、支付宝不提供中心头像功能。
- “三码放置区域”和“图层与权限”采用左侧预览、右侧独立滚动操作。调整预览在码区域超界时继续显示完整图片，并提示需要修正的位置；保存与导出的尺寸校验仍保留。
- 主头像裁切、最多 12 字署名；选择背景后直接在成品预览上拖动位置、拖角缩放和旋转，调整工具位于预览下方，每张背景分别记住设置，预览与导出保持一致。可开放文本、图层选项和保留透明度的颜色叠加；RGB、选择器、图片和预览吸色、浏览器屏幕取色。
- 2048 原尺寸 Canvas 即时预览、4096 PNG 导出，共用渲染器；编辑无防抖等待，复用二维码和着色图层，预览不逐帧编码 PNG；无需额外检查或勾选确认即可下载。
- 管理员登录、服务端会话、密码散列、登录限流、同源检查；模板复制、草稿、选项、素材、权限、发布、历史快照及恢复；乐观并发保护。
- 桌面并排、手机上下排列；未指定可选图层和颜色权限保持锁定。

## 验证

```powershell
npm run typecheck
npm test
npm run build
# 本地服务运行后，使用安装的 Chrome 执行端到端测试
node scripts/qa.mjs
node scripts/qa-reward.mjs
node scripts/qa-default-display.mjs
node scripts/qa-position-workspace.mjs
```

`tests/core.test.ts` 检查三码必填、赞赏码限制、固定布局约束、随机渲染一致性、不可变快照和并发写保护。`scripts/qa.mjs` 使用合成支付内容（不执行真实收款），检查桌面/手机界面、截图识别、裁切、署名上限、高清导出、后台鉴权、跨站拦截。截图和测试导出保存在 `.local/qa`，不进入仓库。

## 发布前需要完成

- 用用户自己的真实微信、支付宝及赞赏截图进行 App 扫码测试；普通二维码解码成功不等于真实收款已经验证。
- 赞赏码自动定位使用图像特征；中心和右下覆盖范围沿用 PSD，应使用实际收款截图检查预览及扫码效果。
- 默认本地种子版本用于预览和验收。后续发布要求管理员勾选 PSD 与覆盖检查完成。不要把本地种子状态当作生产验收通过。
- 提供授权素材，确认字体和图片的分发权。管理员素材库中的“可公开分发”是人工权限记录，不会自动把素材加入仓库。
- 生产服务使用 HTTPS，设置 `APP_ORIGIN` 为准确域名（同时用于同源检查和 Secure Cookie）；持久化 `data` 与已授权的模板资源。SQLite 适合单机持久化部署，不适合无持久卷的 serverless 实例。更换端口时同步修改 `APP_ORIGIN`。
- 密码轮换：生成新盐和 scrypt 散列，修改 `ADMIN_PASSWORD_HASH` 并清除 sessions 表后重启；勿向日志输出密码或密钥。
- 构建对应源码并保留许可证：`npm run source:bundle`。部署 `.local/linkora-source.zip`，通过 `/api/source` 提供；可用 `LINKORA_SOURCE_ARCHIVE` 指定路径。
